# Eve Empire — Desktop Releases

Public download distribution for the **Eve Empire** companion app for EVE Online.

## Downloads

Latest builds are published under [Releases](https://github.com/ederkach/eve-imperium-releases/releases).

- **macOS** — `EveEmpire-X.Y.Z.dmg`
- **Windows** — `EveEmpire-X.Y.Z.msi`

For mobile builds (Android, iOS), see the app's listings on Google Play and the App Store.
